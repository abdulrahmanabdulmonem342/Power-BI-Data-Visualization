# 📊 Data Professional Survey Breakdown — Power BI Dashboard

## 📌 Overview
An interactive **Power BI dashboard** built to analyze survey responses from data professionals worldwide. The project explores key career metrics including salary breakdowns across job titles, work-life balance, happiness with compensation, and popular tech stacks in the data domain.

---

## 📈 Dashboard Preview
![Power BI Dashboard](dashboard.png)

---

## 💡 Key Insights & Visualizations
* **Demographics & Roles:** Survey takers distribution by country and job title (Data Scientist, Data Analyst, Data Engineer, Architect, etc.).
* **Salary Breakdown:** Average salary comparisons across different data roles.
* **Work & Life Satisfaction:** Gauge meters tracking happiness with work/life balance and salary levels.
* **Technology Stack:** Visual breakdown of the most popular programming languages used by professionals (Python, R, C/C++, JavaScript, Java).
